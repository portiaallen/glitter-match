# Development fixtures

This directory is **not** production content.

Files here exist only to exercise the engine, schema, and debug tooling. They must not be treated as Land puzzles, campaign levels, or icon-family canon.

These fixtures use `dev.*` icons, which the production validation profile rejects.

Canonical Land icon families exist as architecture data. They are not campaign puzzles. `data/lab/*` must never be treated as production levels.
